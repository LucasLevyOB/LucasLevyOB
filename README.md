## 🌟 Projeto em Destaque: DepuDados

A **[DepuDados](https://depudados.com.br)** é uma plataforma analítica voltada à transparência e exploração interativa de dados abertos da Câmara dos Deputados do Brasil.

[![DepuDados Preview](imgs/depudados-home.png)](https://depudados.com.br)

### 🚀 Principais Diferenciais:
- **Inteligência Artificial (Ollama / LLM):** pipeline em lote que processa ementas legislativas e categoriza automaticamente matérias em áreas de atuação pública (Saúde, Educação, Segurança, etc.).
- **Score de Eficiência Parlamentar:** algoritmo ponderado que correlaciona a produção legislativa com os gastos de cota parlamentar (CEAP).
- **Visualização Analítica Interativa:** gráficos temporais com `@mui/x-charts` e renderização de grandes volumes de dados via virtualização do DOM com `@tanstack/react-virtual`.
- **Pré-Agregação no MongoDB:** cálculos analíticos pré-consolidados em background via rotinas agendadas em Node.js, viabilizando ordenação global instantânea via `.find().sort()`.
